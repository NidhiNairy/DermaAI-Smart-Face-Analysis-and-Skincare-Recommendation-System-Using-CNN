# DermaAI

## Overview
DermaAI is an AI-powered facial skin analysis and skincare recommendation system that uses CNN-based deep learning and computer vision to identify skin types and common skin concerns from facial images.

## Features
- Skin Type Classification
- Skin Condition Detection
- Personalized Skincare Recommendations
- Image-Based Analysis

## Technologies Used
- Python
- TensorFlow/Keras
- OpenCV
- CNN
- Flask

## Project Outcome
Provides intelligent skincare recommendations based on facial image analysis.
